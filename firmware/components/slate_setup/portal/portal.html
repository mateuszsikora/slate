    Addressing

    The panel proves this before keeping it. If the gateway does not answer within about fifteen seconds, or the address is already taken, it goes back to an automatic one and says which on its screen.

    Web editor access

    Optionally protect the editor with a numeric PIN. When enabled, Slate asks for it every time the editor is opened. Without a PIN, anyone on this network can open it.

    Use 4–12 digits. A forgotten PIN requires a physical factory reset.

    Recovery network security

    Slate's setup network is open by default. For a shared building, set a password for future setup sessions; the panel will show it beside the QR code.

    Use 8–63 characters, or leave this blank to keep the current setting.
